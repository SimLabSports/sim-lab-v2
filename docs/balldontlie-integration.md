# BALLDONTLIE data integration

`BALLDONTLIE_API_KEY` is server-only. A shared Vercel variable must be linked to this project for Production/Preview. Redeploy to inject a newly linked key. No key, email, billing details, or account API response containing credentials is returned to the browser. Only the read-only subscription endpoint is used; the integration never purchases or changes a plan.

`GET /api/statistics/coverage` compares every currently visible market-provider league against explicit BALLDONTLIE sport mappings, research adapters and actual account subscription metadata. Provider catalog mapping is not a claim of endpoint access or completed research coverage. Soccer, tennis, MMA, golf and other event schemas cannot inherit binary basketball or football rules. Unmapped leagues retain precise missing-source reasons.

The event/results adapter covers NBA, WNBA, NFL, MLB, NHL and men's/women's NCAA basketball and NCAA football. It requires exact participant names, a unique event within 15 minutes of the market start, a real timestamp and an explicit scheduled state. Unknown, postponed, delayed and completed states cannot receive new pregame evaluations. Source-specific date, away-team, status and score fields are mapped explicitly.

Basic games endpoints can supply attributed completed-game scoring form, sample size and schedule rest. Only final games before the target start and current time, from the matched season and within 90 days, enter research. One bounded history page is fetched; incomplete pagination is disclosed and cannot be described as complete last-five or season form. All evidence retains its source URL and actual response observation time. It is qualitative research evidence, never an inferred win probability.

NFL, NCAA football, WNBA and NCAA basketball team-game statistics use their documented filters and allowlisted sport-specific metrics when the account indicates paid access and the endpoint succeeds. Injury reports are retrieved only from supported, permitted endpoints. Injury statuses are not comprehensive clearance, healthy status, confirmed starters or guaranteed absence of injury. No lineup/injury clearance flag is set from an empty list. Statistical aggregation admits only identified teams and verified historical game IDs; multiple rows for the same team/game are not combined into invented totals.

MLB's official public input packet and the NFL public fallback remain usable if BALLDONTLIE is unavailable or not entitled. Successfully matched supplementary evidence can be merged with those packets without erasing missing inputs, risks or source attribution. Other supported team sports use their own BALLDONTLIE packet. Expert Consensus never treats provider game data or GCM research as analyst picks.

Calls are cached and deduplicated; timeouts, permission errors, rate limits and schema failures return safe reasons without provider response bodies or credentials. Account verification is cached ten minutes. GCM research version 4 invalidates older saved incomplete assessments so newly available inputs can be evaluated. Existing approval, price, model-calibration, uncertainty and three-perspective agreement requirements remain unchanged.
